# API Reference

Base URL (local): `http://localhost:8000`

Interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc`.

## Health

### `GET /health`
Returns backend + MongoDB connectivity status.

```json
{ "status": "ok", "mongo_connected": true }
```

## Videos

### `POST /api/videos/upload`
Multipart file upload. Accepts `.mp4`, `.mov`, `.mkv` up to `MAX_UPLOAD_SIZE_MB`.
Starts background processing immediately; returns status `uploaded`.

### `POST /api/videos/url`
Form field `url` — a permitted YouTube URL. Validates and fetches metadata via `yt-dlp`, rejects age-restricted/live videos, downloads, and starts processing.

### `GET /api/videos/{video_id}`
Returns video metadata (filename, duration, status, source).

### `GET /api/videos/{video_id}/status`
Returns current `processing_status` (`uploaded → extracting_audio → transcribing → extracting_frames → embedding → indexing → ready`, or `failed`).

### `GET /api/videos/{video_id}/segments`
Returns all temporal chunks with transcript text and formatted timestamps.

### `DELETE /api/videos/{video_id}`
Deletes the stored video file, MongoDB segment/metadata documents, and all associated Pinecone vectors.

## Questions & Answers

### `POST /api/videos/{video_id}/questions`
Body:
```json
{ "question": "What did the speaker say about AI?", "answer_mode": "standard" }
```
`answer_mode` ∈ `standard | simple | detailed | technical`.

Requires the video to be `ready`. Returns a grounded answer plus text and visual evidence, each with timestamps and a relevance score.

### `POST /api/videos/{video_id}/summary`
Body:
```json
{ "summary_type": "short" }
```
`summary_type` ∈ `short` (5–8 bullets) | `detailed` (section-wise, hierarchical).

## Error handling

- `400` — validation errors (bad extension, oversized file, invalid/restricted YouTube URL)
- `404` — video or resource not found
- `409` — video exists but isn't `ready` yet (question/summary requested too early)
